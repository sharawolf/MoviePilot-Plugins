# Agent 桌宠形象

v3.0.0 — 支持 Codex Pet 压缩包导入、角色库与动作预览，适配手机触摸和可视区域，保留原有角色和桌宠控制台。

本地适配候选，支持 MoviePilot v3.1.3 及以上。原作者：ifsherlock；本次 V3 维护：z2561221。

当前仓库没有此插件的旧代索引，使用 `v3_only` 分类；该分类不改变既有四个插件的版本例外。发布前须通过版本门禁、后端回归与前端构建测试。

在「基础设置」启用插件及“替换智能助手入口”，在「形象与行为」选择“克里斯蒂娜”，保存后应用。MP v3.1.4 及以上版本在智能助手面板点击“更换形象”，选择“Agent 桌宠”一次；选择由宿主持久保存，刷新页面后自动加载插件中选定的角色，无需再次打开插件页。单击桌宠打开原生智能助手，拖拽不会误触发对话。

控制台分为「运行总览 / 基础设置 / 形象与行为 / 动作预览」。总览显示已保存配置和当前页面状态；预览使用当前草稿，动作测试仅影响预览区，调试信息默认收起。界面跟随宿主明暗主题，移动端采用顶部导航。

在「形象与行为」点击「导入 Pet」，选择 ZIP，查看名称和动画后「保存到角色库」，最后点击底部「保存设置」应用所选角色。导入不会覆盖三个内置角色；重复导入同一角色自动复用，切换到其他角色并保存后可移除不需要的导入角色。

支持 Codex Pet v1（1536×1872、9 行）和 v2（1536×2288、11 行）PNG/WebP 图集，每格 192×208，建议使用透明背景。动作按每行实际有画面的格子播放，多余帧照常使用，空白帧跳过；整行动作或视线缺失时复用待机画面，待机也缺失则使用首个可用动作。原始图片保持不变，不透明背景也可导入，仅整张全透明图无法显示。ZIP 内须有唯一 `pet.json`，通过其 `spritesheetPath` 找到图集；根目录、单层目录和完整备份中的嵌套 `package/` 均可识别。缺少 `spriteVersionNumber` 时按图集尺寸判断。压缩包最多 64 MiB、1024 项，图集最多 20 MiB；多个角色请分别打包。

手动动作预览在屏幕边缘仍完整播放；鼠标指向屏幕角落时，角色按可到达位置停稳，避免反复转向。

导入角色支持九组原生动作、平滑游走、拖动与单击打开 MP 助手；跑动步频跟随速度，接近鼠标时平滑减速；近距离优先目光跟随，范围为角色图格高度的一半（最小 32px，2 倍大小时约 104px），离开范围再增加 20% 缓冲；上下偏差超过外圈才起跳，2 倍大小时约 125px。跳跃落点限制在可到达范围内，接近鼠标后减速站定并恢复凝视；鼠标跟随期间不触发随机小跳。拖动后保留松手高度，自动游走偶尔小跳并落回该高度；开启「跟随鼠标」后，可沿弧线向上或向下跳到鼠标所在高度。动作预览中的「跳跃」会实际起跳并落回原位，窗口边界会限制活动范围。v2 还支持 16 方向视线。爬墙、吸顶和睡觉没有对应标准素材，因此不提供这些动作；工作、等待、失败和检查动作可在预览中手动播放，尚未关联 MP 助手任务状态。动画内容按导入素材呈现，不重新生成画面；角色细节的流畅度仍取决于原始图集。

角色文件存于当前插件实例 `get_data_path()/pets/`，更新代码或目标 reload 后保留。导入仅读取清单和图片，不执行压缩包里的脚本；动画图片通过内容寻址 URL 提供，角色列表与导入、移除接口需登录认证。

手机上轻点页面桌宠打开助手，拖动调整位置；滑动页面不会触发鼠标追逐，多指触摸只由最先按下的主触点拖动。窄屏或触摸设备上的全局 Pet 图格宽度不超过可用宽度的 32% 且不超过 128px，不改写保存的大小设置。支持 `visualViewport` 的浏览器中，软键盘、横竖屏与缩放变化会重新约束位置；安全区取浏览器提供的 `env(safe-area-inset-*)`。不支持这些接口的浏览器回退窗口尺寸。触摸设备没有鼠标悬停，因此目光跟随仍用于鼠标输入；手机不自动模拟鼠标追逐。

损坏的角色元数据会被跳过并记录日志，设置页仍可切换回内置角色；原文件不会自动删除。组件和全局运行器释放时会清除待执行的动作回调。

配置页和侧栏页统一调用宿主配置保存接口并回读确认。读取失败不会将默认值当作实际配置，刷新保留未保存修改，保存失败保留草稿；提交后回读失败时先刷新确认，避免直接重复提交。预览离开页面后释放动画、观察器与计时器，隐藏标签页暂停预览，减少动态效果设置下默认暂停。

后端初始化、配置生效、Pet 预览/导入/移除及失败原因写入宿主的插件日志 `agentmascot.log`；状态轮询与鼠标逐帧动作不刷日志。浏览器控制台 `[AgentMascot]` 记录页面挂载、配置变化、运行器替换和读取失败/恢复；`window.__AgentMascotGlobalLoader.getState()` 可查看当前构建标识、是否收到鼠标输入、纵向阈值和运动状态。浏览器日志与后端日志独立，提供脚本不代表页面已执行。

MP v3.1.4 通过 `get_agent_pets()` 与联邦 `./AgentPet` 加载官方 `stage` 形象，宿主负责选择、整页刷新恢复、退出登录及形象切换后的卸载。插件向宿主上报气泡锚点和拖拽状态，通过 `agent.open()` 打开助手；配置读取或图片加载失败交由宿主回退。打开插件设置页不会覆盖宿主选择，切换回“内置机器人”后不会被设置页重新替换。角色仍在插件内选择，原有导入素材与动作保持可用。

MP v3.1.3 仍保留打开插件页后启动的旧入口，整页刷新后需要再次打开。独立脚本方式仍可使用受认证的 `/api/v1/plugin/AgentMascot/loader`，但不会抢占已挂载的官方 stage。插件不修改宿主前端或管理员默认形象；同一未发布周期继续使用 v3.0.0。

保留小天照、奶龙、克里斯蒂娜的素材和 idle / walk / run / follow / drag / sleep / wall / ceiling / fall 动作。JSON API 明确返回 `success / message / data`，插件界面复用宿主注入的 API 客户端。
