# Agent 桌宠形象

v1.0.0 — 适配 MoviePilot V3，重做桌宠控制台，完善配置保存反馈，保留原有角色与动作。

本地适配候选，支持 MoviePilot v3.1.3 及以上。原作者：ifsherlock；本次 V3 维护：z2561221。

在「基础设置」启用插件及“替换智能助手入口”，在「形象与行为」选择“克里斯蒂娜”，保存后应用。打开侧栏“Agent 桌宠”或插件详情页后，桌宠会在当前页面会话中接替原生助手入口；单击桌宠打开原生智能助手，拖拽不会误触发对话。

控制台分为「运行总览 / 基础设置 / 形象与行为 / 动作预览」。总览显示已保存配置和当前页面状态；预览使用当前草稿，动作测试仅影响预览区，调试信息默认收起。界面跟随宿主明暗主题，移动端采用顶部导航。

配置页和侧栏页统一调用宿主配置保存接口并回读确认。读取失败不会将默认值当作实际配置，刷新保留未保存修改，保存失败保留草稿；提交后回读失败时先刷新确认，避免直接重复提交。预览离开页面后释放动画、观察器与计时器，隐藏标签页暂停预览，减少动态效果设置下默认暂停。

切换 MP 页面后桌宠继续运行。整页刷新后需要再次打开桌宠页面；当前官方宿主没有自动执行全局插件脚本的入口，本插件不修改宿主前端、不注入全局配置。已有的独立脚本加载方式仍可使用受认证的 `/api/v1/plugin/AgentMascot/loader` 接口。停用插件后，已打开页面在下一次状态检查时恢复原生入口。

保留小天照、奶龙、克里斯蒂娜的素材和 idle / walk / run / follow / drag / sleep / wall / ceiling / fall 动作。JSON API 明确返回 `success / message / data`，插件界面复用宿主注入的 API 客户端。

恢复来源：`agentmascot_v0.1.18-behavior-actions-slim.zip`，SHA-256：`019cbc33013486db096d31547738cf948bdeaad7798734977b79cdcdb2c11686`。原包源码版本为 0.1.15、前端包版本为 0.1.16；首次 V3 迁移统一为 1.0.0。原包只包含编译模块；本次 UI 维护重建了 `src/` 下的 Vue 源码及锁定依赖的 Vite 工程。`runtime/` 保存恢复的动作引擎、素材和入口适配器，构建时复制到 `dist/assets/`；其中 `runtime-BCybTabx.js` 与原包保持逐字节一致。

前端构建：在本插件目录执行 `npm ci`、`npm run build`。宿主提供 Vue 与 Vuetify 组件，构建产物不重复打包宿主 UI 库。保留 `Config`、`Page`、`AppPage` 和历史 `PluginEntry` 联邦入口。

验证入口：`tests/v3/agentmascot/test_plugin.py` 与 `npm test`。测试包含配置草稿/回读、请求归属、真实 Vue 组件导航和保存事件、预览清理及原有全局入口回归；不替代浏览器视觉验收或线上发布。
